プライバシーポリシー

当アプリケーション（以下「本アプリ」）は、 ユーザーのプライバシーを尊重し、個人情報の保護に努めます。 本プライバシーポリシーでは、Googleアカウント連携およびGoogle APIを通じて取得する情報の取り扱いについて説明します。

1. 取得する情報

本アプリでは、Googleアカウント連携機能をご利用いただく際に、以下の情報を取得・利用します。

  • Googleアカウントの基本情報（氏名・表示名、メールアドレス）
  • GoogleスプレッドシートおよびGoogleドライブへのアクセス権限（本アプリが管理する専用台帳シートの作成・読み取り・更新）

2. 利用目的

取得した情報は、以下の目的でのみ使用します。

  • 本アプリで管理する寺院台帳データ（檀家情報・過去帳・会計等）をお客様ご自身のGoogleスプレッドシートと自動同期・バックアップするため
  • 本アプリの操作履歴（変更・削除ログ）において、操作者を正確に記録・識別するため

3. データの共有・第三者提供について

本アプリは、取得したGoogleユーザーデータやスプレッドシート内のデータを第三者に提供、販売、 または広告配信等の目的で利用することは一切ありません。

4. Google API 利用に関する開示

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用要件を含む）に準拠します。

5. お問い合わせ

本ポリシーに関するご質問は、管理者までお問い合わせください。
